GAME ORGANIZATION

personal goals:
- high-poly, animated 3D models
- dynamic (simple) soundtrack
- highest possible lighting fidelity

developer goals:
- prevent hard links between systems (use signal patterns)

game jam goals:
- theme: from the stars (must be horror themed)
- community prompts:
  - ignoring the warnings
  - rapidly evolving
  - abandon ship
  - strange signs
- moral:
  - no generative ai
  - credit any pre-made/asset packs
  - original and created during event OK
- system:
  - must be downloadable from itch
  - 2GB limit

game structure:
- input is only wasd/left-joystick to move and mouse/right-joystick to look
  - no jumping: no need to calculate gravity
- entire game takes place in one scene
- set number of monsters and collectibles spawn dynamically and randomly, once at start
- monsters can wander, collectibles remain in place
